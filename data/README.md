# Каталог подрядчиков

Сайт принимает CSV с исходной схемой трека 06.

## Обязательные колонки

```text
id
anon_name
categories
city
city_imputed
synthetic
price_from_kzt
price_imputed
event_formats
languages
max_hours
busy_dates
description
```

## Формат значений

- Несколько значений в `categories`, `event_formats`, `languages` и `busy_dates` разделяются символом `|`.
- `busy_dates` хранит даты в формате `YYYY-MM-DD`.
- `price_from_kzt` — число без символа валюты.
- Пустой `max_hours` означает, что услуга не требует присутствия подрядчика ограниченное число часов.
- Флаги `synthetic`, `city_imputed` и `price_imputed` используют значения `True` или `False`.

## Как подключить каталог

1. Откройте сайт.
2. Нажмите «Подключить CSV-каталог».
3. Выберите CSV из набора организатора.
4. Проверьте блок «Checkpoint данных»: число профилей, городов, категорий и колонок должно отобразиться без ошибки.

При запуске через `python run.py` сайт передаёт разобранный каталог своему серверу при поиске; сервер проверяет данные и не сохраняет пользовательский каталог. Если настроен внешний AI-шлюз, ему передаются параметры запроса и факты максимум трёх выбранных профилей. В автономном режиме `file://` обработка остаётся в браузере.

Сервер также может загрузить исходный CSV/JSONL напрямую через переменную `CONTRACTORS_PATH`. Без неё используется `demo-contractors.json`: **16 синтетических демонстрационных профилей**, а не официальный набор из 66 записей. Подробности и контракт API — в [BACKEND.md](../BACKEND.md).

## Правило источника истины

Даты занятости, город, категории, форматы, цена, язык и длительность берутся только из CSV. AI может сформулировать объяснение, но не может добавлять факты о подрядчике.
