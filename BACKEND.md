# Бэкенд подбора подрядчиков — ветка backend

Это сервер EventMatch AI для кейса #79-lite. Проект AI Sana с карточками бизнес-задач сюда не переносился.

## Запуск

Python 3.11+ (проверено на 3.13):

```text
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux вместо предыдущей строки: source .venv/bin/activate
python -m pip install -r requirements.txt
python run.py
```

В PyCharm выберите интерпретатор `.venv`, установите зависимости и запустите `run.py`.

- Сайт с подключённым API: http://127.0.0.1:8001/
- Интерактивная документация: http://127.0.0.1:8001/docs
- Схема: http://127.0.0.1:8001/openapi.json

Порт 8001 выбран, чтобы не конфликтовать с другим локальным сервером на 8000. Можно изменить переменной PORT. `127.0.0.1` доступен только на вашем компьютере.

## Что реализовано

- `GET /api/health` — состояние, число профилей, наличие настройки AI.
- `GET /api/catalog` — текущий каталог и его источник.
- `POST /api/search` — строгий отбор, до 3 карточек, объяснения и причины исключений.
- Сервер отдаёт существующие HTML/CSS/JS сайта и подключающий API файл `api-client.js`.
- Пользовательский CSV отправляется этому серверу только для текущего запроса: глобальный каталог и каталоги других пользователей не меняются.

Пример тела POST `/api/search`:

```json
{
  "city": "Алматы",
  "category": "Ведущий",
  "event_format": "корпоратив",
  "event_date": "2026-10-15",
  "budget": 2000000,
  "language": null,
  "duration": null,
  "use_ai": false
}
```

Необязательное поле `contractors` принимает массив профилей (1–2000), соответствующих схеме каталога. Без него используется каталог сервера. Поля CSV с `|` и JSON-массивы поддерживаются одинаково; ID должны быть уникальны. Неверные строки, даты, числа, флаги и неизвестные поля возвращают 422. `max_hours: null` или пустая строка — услуга не привязана к присутствию, а не обещание неограниченной работы.

## Ответ и алгоритм

Ответ содержит `status`, `message`, `results`, `total_candidates`, `total_matched`, `exclusions`, `explanation_mode`, `warning`, `dataset_source`.

`status` строго различает:

- `matched`: найдены подходящие профили;
- `no_category`: в городе нет указанной категории;
- `no_match`: категория есть, но условия не выполнены.

Сначала город + категория, затем обязательные фильтры по дате, формату и бюджету; если указаны — язык и длительность. Сравнение названий без учёта регистра. Цена «от» лишь проходит бюджетный фильтр, окончательная стоимость не гарантируется.

Все прошедшие кандидаты ранжируются по начальной цене (меньше — выше), затем по уникальному ID. Это простая объяснимая стратегия, не оценка качества услуг. `score = 1 - price_from_kzt / budget` — доля бюджета сверх начальной цены, не вероятность пригодности. Случайности нет, изменение порядка строк в файле не меняет выдачу. ИИ не влияет на порядок и состав списка.

Каждая карточка содержит `contractor`, `score`, `explanation`. Объяснение включает дату, формат, начальную цену, бюджет и конкретные характеристики профиля. При результате меньше трёх сообщается причина. `exclusions` считает все нарушенные условия; один кандидат может попадать в несколько причин, поэтому суммы не следует складывать для получения числа исключённых — используйте `excluded_count`.

Календарь ограничен 23.09.2026–31.12.2026. Запросы вне окна отвергаются: отсутствие даты в файле не доказывает свободное время за пределами известного календаря.

## Данные

Основной каталог — `data/contractors.csv`, добавленный командой в main: **66 профилей**, проверяемых при старте сервера. Флаги качества сохраняются из исходных данных. `data/demo-contractors.json` содержит отдельные **16 синтетических профилей** для изолированных тестов; встроенный демо-каталог интерфейса также явно помечен синтетическим.

Для другого набора укажите переменную окружения `CONTRACTORS_PATH` (путь к CSV/JSONL/JSON). Без настройки используется `data/contractors.csv`. При ошибке файла сервер останавливает запуск, не подменяет источник демо-данными. Исходные файлы не перезаписываются. Обычный запрос фронтенда не содержит каталог — используется серверный; только загруженный пользователем CSV или выбранный демо-каталог передаётся в поле `contractors`.

Пример PowerShell перед запуском:

```powershell
$env:CONTRACTORS_PATH = 'data/contractors.csv'
python run.py
```

## AI и обработка ошибок

На сайте запрашивается `use_ai: true`; при отсутствии ключа или ошибке модели сервер явно возвращает предупреждение и шаблон. При работающем ключе OpenAI выбирает факты для объяснений.

Для AI-функции доступны собственный HTTP-шлюз (`AI_API_URL`, `AI_API_KEY`) или прямая интеграция OpenAI Platform (`AI_PROVIDER=openai`, `OPENAI_API_KEY`, `OPENAI_MODEL=gpt-4.1-mini`). OpenAI используется по умолчанию; для собственного шлюза задайте `AI_PROVIDER=gateway`. Модель, настройки и размещение описаны в DEPLOYMENT.md. `.env.example` — справка, файл `.env` автоматически не загружается; задавайте переменные в терминале или конфигурации PyCharm.

Шлюзу отправляются промпт из `backend/ai.py`, параметры `query` и `facts` вида:

```json
{"facts": {"DEMO-002": {"languages": "языки работы: русский", "duration": "присутствие до 8 ч", "formats": "заявленные форматы: свадьба, юбилей, корпоратив"}}}
```

Модель выбирает два полезных факта для каждого переданного ID:

```json
{"selections": {"DEMO-002": ["languages", "duration"]}}
```

Проверяются точное множество ID, известные ключи и ровно два различных факта. Произвольный текст модели пользователю не выводится: итоговые 1–2 предложения собираются сервером из подтверждённых полей. Ошибки HTTP/JSON, неизвестные факты и превышение 7 секунд ожидания дают шаблонный ответ с предупреждением. Фоновый сетевой вызов ограничен таймаутами HTTP; прерванное ожидание не всегда мгновенно прекращает выполняющийся поток. Для публичного сервиса потребуются ограничения запросов и нагрузки. Повторный запрос гарантирует тот же порядок карточек; выбор фактов внешней моделью может отличаться.

## Проверка

```text
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

Тесты проверяют три исхода, смену даты, редкую категорию, площадки, ограничения языка/времени/цены, независимость каталогов пользователей, загрузку CSV/JSONL, ошибки ввода, стабильность порядка и валидный/невалидный AI-ответ. Реальный внешний AI-сервис без адреса и ключа не проверялся.

Для живого демо откройте сайт и нажмите кнопки «Плотная: ведущий», «Дата меняет выдачу», «Редкая: флорист», «Нет категории в городе», «Все заняты». Полный официальный набор нужно подключить отдельно перед защитой.

## Ограничения MVP

Нет бронирования, платежей, уведомлений, регистрации и обучения моделей. Работает локально; для публичного запуска отдельно настраиваются хостинг, HTTPS и защита от перегрузки. CORS по умолчанию допускает localhost:3000/5173; список меняется через CORS_ORIGINS. Статические файлы отдаются по явному списку — содержимое `.env`, `.git` и Python-файлы через сервер не раскрываются.

Старый автономный режим `file://` использует браузерный алгоритм; для проверки **серверного** сценария всегда запускайте `python run.py` и открывайте адрес на порту 8001.
