# Размещение EventMatch и модель NVIDIA

## Модель и обязанности

Выбрана `nvidia/nemotron-3-super-120b-a12b`, вызываемая через NVIDIA NIM API.
Источник и пример протокола: https://build.nvidia.com/nvidia/nemotron-3-super-120b-a12b
На 23.09.2026 страница показывает доступный API для прототипирования; доступ и лимиты
конкретного аккаунта нужно проверить отдельно.

Модель выбирает два наиболее полезных факта для объяснения каждой из максимум трёх карточек.
Сервер проверяет ID и ключи фактов и собирает текст из исходных данных. Модель не получает
управление компьютером, не бронирует подрядчиков, не изменяет бюджет, фильтры или порядок.
Это ограниченная AI-функция, а не чат или автономный агент для выполнения команд.

OpenClaw, NemoClaw и Hermes в Brev — готовые среды агентов; их запуск не подключает
модель к сайту автоматически. В этой архитектуре достаточно CPU-сервера и NVIDIA API,
собственный GPU и среда автономного агента не требуются.

## Настройки

```text
AI_PROVIDER=nvidia
NVIDIA_API_KEY=<секретный ключ>
NVIDIA_MODEL=nvidia/nemotron-3-super-120b-a12b
```

Кредиты Brev и доступ к NVIDIA API проверяются отдельно. Ключ вводится только в секреты
хостинга или окружение запуска. Не отправляйте его в чат и не коммитьте в GitHub.
Python `run.py` не загружает `.env` автоматически; задавайте значения в PyCharm/терминале.
Docker Compose читает `.env` и передаёт перечисленные в compose.yaml переменные.
`.env*` исключены из Docker-контекста; образ не содержит ключей.

При успешном ответе модели `/api/search` возвращает `explanation_mode: ai_fact_selection`,
`ai_provider: nvidia` и `ai_model`. `/api/health` показывает только наличие настройки,
не успешную проверку ключа. При отсутствии ключа, ошибках, невалидном JSON или превышении
7 секунд ожидания срабатывает шаблон с предупреждением. Реальная интеграция без ключа
не проверена: тесты используют имитацию ответа NVIDIA. Скорость проверяется отдельно
на реальном аккаунте; если задержки выше лимита, пользователь увидит шаблон.

## Локально

Установите зависимости, задайте переменные выше и выполните `python run.py`.
Адрес: http://127.0.0.1:8001/ .

## В Brev или на Docker-хостинге

В CPU-окружении с Docker клонируйте ветку `backend`, если на сервере настроен доступ к репозиторию:

```text
git clone --branch backend --single-branch https://github.com/BAITC-Hacks/hack-86169f09-nebula.git
cd hack-86169f09-nebula
docker compose up -d --build
docker compose logs --tail=50 eventmatch
```

Закрытый репозиторий нельзя клонировать без авторизации. Можно передать архив конкретного
коммита через SSH и распаковать его на сервере; GitHub-токен в этом случае не требуется.

До подключения модели добавьте секрет NVIDIA в окружение или локальный `.env`.
По умолчанию Compose привязывает порт к `127.0.0.1:8001` машины: это подходит для проверки через
SSH-туннель или HTTPS-прокси на той же машине. Публичная ссылка автоматически не создаётся.
Подключите HTTPS-прокси/домен платформы к сервису, проверьте доступ и лимиты запросов.
Для доступа прокси из другого контейнера используйте общую Docker-сеть и адрес eventmatch:8001.
Для Brev Secure Links укажите `BIND_ADDRESS=0.0.0.0` в серверном `.env`, выполните
`docker compose up -d` и создайте HTTP Secure Link на порт 8001. Облачный firewall
не должен разрешать прямой доступ к порту 8001 из интернета: доступ идёт через прокси Brev.
По умолчанию сохраняйте аутентификацию Secure Link; публичный режим настраивается отдельно.
Не открывайте панель управления агента или секреты вместе с публичным сайтом.

Контейнер работает от непривилегированного пользователя, имеет health check `/api/health`
и слушает `0.0.0.0` внутри. Без Docker: сборка `pip install -r requirements.txt`,
запуск `python run.py`, переменные `HOST=0.0.0.0` и `PORT`, выданный платформой.

Создание платного ресурса требует проверки баланса кредитов, тарифа и лимита расходов.
23.09.2026 Docker-сборка проверена на Brev/GCP. Сайт размещён по адресу
https://8001-qfrtcqsej.gobrev.dev/ с доступом через разрешённый аккаунт NVIDIA.
Проверены загрузка страницы и ресурсов, `/api/health`, подбор трёх вариантов и пустой
результат при недостаточном бюджете. NVIDIA API ещё не подключён: выдача ключа требует
подтверждения телефона владельцем аккаунта. Пока используются проверенные шаблоны объяснений.
Первоначальный setup script в Brev помечен Failed из-за клонирования закрытого репозитория;
последующая установка из переданного архива выполнена успешно.

## Данные

Пока включены 16 синтетических профилей. Официальный CSV нужно предоставить отдельно.
Добавьте его в data и настройте `CONTRACTORS_PATH=data/contractors.csv` в окружении
сервиса; для Compose дополнительно добавьте эту переменную в environment.
