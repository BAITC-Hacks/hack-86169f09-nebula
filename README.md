# EventMatch AI

Команда Nebula, HackAlem AI, кейс #79-lite «Умный подбор подрядчиков».

Фронтенд и FastAPI работают как одно приложение: форма получает каталог через
`GET /api/catalog`, отправляет параметры в `POST /api/search` и показывает до трёх
карточек с объяснениями и причинами исключений. Отдельный Node.js matcher больше
не используется. OpenAI подключён только на стороне Python-сервера.

## Запуск

Нужен Python 3.11+. В терминале PyCharm из корня проекта:

```text
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python run.py
```

На macOS/Linux вместо команды активации: `source .venv/bin/activate`.
Сайт: http://127.0.0.1:8001/ · API: http://127.0.0.1:8001/docs.
`npm start` и `npm run dev` также запускают этот Python-сервер; предварительно
нужно активировать его окружение. Можно задать путь к Python переменной `PYTHON`.
Docker: `docker compose up -d --build`.

## Данные и подбор

По умолчанию используется добавленный командой `data/contractors.csv`: 66 профилей,
13 обязательных полей, календарь 23.09–31.12.2026. Сервер проверяет структуру, даты,
цены и уникальность ID при запуске. Неверный каталог не подменяется демо-данными.
Для другого файла задайте `CONTRACTORS_PATH`. Метки synthetic, city_imputed и
price_imputed сохраняются из CSV и видны на карточках.

Загруженный через интерфейс CSV используется только в запросах данного посетителя.
Кнопка демо-каталога переключает на синтетические примеры. Открытие index.html через
file:// оставляет отдельный офлайн-деморежим без AI; рабочий сайт запускайте сервером.

Отбор: город, категория, формат, бюджет, свободная дата, при необходимости язык и
длительность. Порядок — цена «от», затем ID; AI не меняет список и порядок кандидатов.
При ошибке API интерфейс показывает ошибку, а не незаметно переключает алгоритм.

## OpenAI

Задайте на сервере `AI_PROVIDER=openai`, `OPENAI_API_KEY` и
`OPENAI_MODEL=gpt-4.1-mini`. Ключ не нужен браузеру и не должен попадать в Git.
Без ключа/при ошибке модели подбор работает с шаблонным объяснением и предупреждением.
Модель выбирает подтверждённые факты для объяснений, ответ проверяется сервером.
Python не читает `.env` автоматически; используйте окружение PyCharm/терминала.
Docker Compose читает `.env`. Подробнее: [DEPLOYMENT.md](DEPLOYMENT.md).

## Проверка и демонстрация

```text
python -m pip install -r requirements-dev.txt
python -m pytest -q
node --test tests/frontend.test.cjs
```

Кнопки под формой заполняют пять сценариев: плотная категория, другая дата,
редкая категория, отсутствие категории в городе и кандидаты без совпадений.
Результаты зависят от выбранного каталога; повтор одинакового запроса сохраняет
порядок. Все штатные поиски используют серверный CSV, пользовательские — свой файл.

Архитектура: HTML/CSS + JavaScript → FastAPI → проверенный CSV → строгий отбор →
необязательный OpenAI Responses API → карточки. Бронирования и платежей нет.
